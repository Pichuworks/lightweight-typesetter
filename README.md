# 轻排：中文 TXT 自动排版 MVP

一个无需构建、无需服务器的浏览器端原型。直接打开 `index.html` 即可使用。

## 已实现

- 粘贴纯文本与上传 `.txt`
- UTF-8 优先读取，失败时尝试 GB18030
- 自动清理多余空行与行尾空格
- 常见中文章节标题识别
- 对疑似硬换行文本进行段落恢复
- 四套模板：舒适阅读、书籍正文、简洁文章、紧凑打印
- 字体、字号、行距与页面主题微调
- 手机优先界面
- 浏览器本地草稿保存
- PDF / 打印、长图预览、复制整理后文本
- 原始换行与自动整理切换

## 本地运行

### 最简单

直接双击 `index.html`。

### 推荐

部分浏览器会限制本地文件的剪贴板能力，可在目录中运行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 当前边界

- 标题和段落识别使用本地规则，不接入 AI。
- 超长文本可能超过浏览器长图画布上限，此时使用 PDF 导出。
- 中文字体调用系统已安装字体，未打包任何商业字体。
- 首版未加入 DOCX、EPUB、图片与复杂图文混排。
